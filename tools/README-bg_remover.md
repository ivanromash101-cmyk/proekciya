# Удаление фона с фото

Модуль `bg_remover` убирает задний фон с фотографии (нейросеть BiRefNet portrait),
затем проверяет и исправляет результат: убирает оторванные куски фона, бледный шум
и цветную кайму, заделывает мелкие дырки, сглаживает края.

**Сохраняется только PNG без фона.** Оригинал удаляется, но только после того, как
результат успешно записан. Если обработка не удалась, оригинал остаётся на месте.

## Установка

```bash
pip install -r requirements.txt
```

При первом запуске модель (~930 МБ) скачивается в `%USERPROFILE%\.rembg\models`.
Другую папку можно задать переменной окружения `U2NET_HOME`. Это удобно, если модель
нужно положить вместе с приложением.

Скорость: около 45 секунд на фото 3000×3000 на обычном процессоре. Загрузка модели
занимает несколько секунд и происходит один раз.

## Вариант 1. Приложение на Python

Скопируйте папку `bg_remover` в проект.

```python
from bg_remover import remove_background_file, remove_background_bytes, warmup

warmup()  # необязательно: загрузить модель заранее, при старте приложения

# Файл → файл. Сохранит фото_no_bg.png, удалит фото.jpg
png_path, report = remove_background_file("фото.jpg")
png_path, report = remove_background_file("фото.jpg", output_dir="без фона")
png_path, report = remove_background_file("фото.jpg", keep_original=True)

# Байты → байты PNG, на диск ничего не пишется
png_bytes, report = remove_background_bytes(open("фото.jpg", "rb").read())
```

`report` — список строк о том, что проверка нашла и исправила. Строки с `⚠`
означают, что результат стоит проверить глазами.

Параметры всех функций: `fix=False` отключает проверку и исправление, `crop=True`
обрезает прозрачные поля вокруг объекта.

Функции можно вызывать из разных потоков. Модель загружается один раз. Но обработка
тяжёлая, поэтому в интерфейсе её стоит запускать в фоновом потоке.

## Вариант 2. Любой язык — командная строка

```bash
python -m bg_remover фото.jpg папка_с_фото -o "без фона" --json
```

На каждый файл печатается одна строка JSON:

```json
{"input": "фото.jpg", "output": "без фона\\фото_no_bg.png", "report": ["Края сглажены"]}
{"input": "битый.jpg", "error": "cannot identify image file ..."}
```

Код выхода: `0` — всё обработано, `1` — были ошибки. Флаги: `--keep-original`,
`--crop`, `--no-fix`. Без `-o` результат сохраняется рядом с оригиналом.

Каждый запуск заново загружает модель (несколько секунд). Если фото много или
они приходят постоянно, лучше использовать сервер.

## Вариант 3. Любой язык — HTTP-сервер

```bash
python -m bg_remover.server --port 8765
```

Модель загружается один раз при старте сервера. Сервер ничего не пишет на диск:
фото приходит в запросе, результат уходит в ответе. Сохраняет его само приложение.

| Запрос | Ответ |
|---|---|
| `POST /remove-background`, тело — байты фото | `200`, `image/png` — фото без фона |
| `?crop=1` | обрезать по объекту |
| `?fix=0` | без проверки и исправления |
| `GET /health` | `{"status": "ok", "model": "birefnet-portrait"}` |

Отчёт проверки приходит в заголовке `X-Report` (JSON). Ошибки приходят в JSON
`{"error": "..."}`: `400` — пустой запрос, `413` — файл больше 40 МБ,
`415` — не изображение, `422` — не удалось обработать.

По умолчанию сервер доступен только с этого компьютера. Чтобы принимать запросы по
сети, добавьте `--host 0.0.0.0`.

Пример на C#:

```csharp
using var http = new HttpClient { Timeout = TimeSpan.FromMinutes(3) };
var photo = new ByteArrayContent(File.ReadAllBytes("photo.jpg"));
var response = await http.PostAsync("http://127.0.0.1:8765/remove-background", photo);
response.EnsureSuccessStatusCode();
File.WriteAllBytes("photo_no_bg.png", await response.Content.ReadAsByteArrayAsync());
File.Delete("photo.jpg");  // сохраняем только фото без фона
```

Пример на JavaScript:

```js
const res = await fetch("http://127.0.0.1:8765/remove-background", { method: "POST", body: file });
const png = await res.blob();
```

## Окно для ручной правки

`python remove_bg.py` открывает окно: результат можно посмотреть и поправить кистью
(«Вернуть» / «Стереть»). В приложение окно встраивать не нужно, оно для ручной работы.
