# Проекция

Приложение для подбора размера одежды: 3D-фигура человека по меркам, автоматический
скан по фото, своё лицо на модели. Работает на Android-телефоне и на ноутбуке.
Подходит незрячим (озвучка, TalkBack, голосовой ввод, пошаговый режим) и глухим
(все сообщения дублируются текстом и подсветкой).

---

## 1. Получить APK для телефона (без установки программ)

Приложение собирается само на сервере GitHub. Нужен только бесплатный аккаунт.

1. Зарегистрируйтесь на https://github.com и нажмите **New repository**
   (зелёная кнопка «New» или https://github.com/new).
   Имя — например `proekciya`, тип **Private** или **Public**, нажмите **Create repository**.
2. На странице репозитория нажмите **uploading an existing file**.
3. Распакуйте архив и перетащите в окно браузера **всё содержимое** папки
   `proekciya` (файлы и папки `www`, `scripts`, `assets`, `.github` и остальные).
   Внизу нажмите **Commit changes**.
4. Откройте вкладку **Actions**. Там запустится «Собрать APK» (жёлтый кружок).
   Сборка идёт 8–12 минут, затем кружок станет зелёной галочкой.
5. Откройте на телефоне страницу репозитория → **Releases** (справа) →
   последняя сборка → **proekciya.apk**. Скачайте и откройте файл.
6. Android спросит разрешение «Устанавливать из этого источника» — разрешите для браузера.
   Значок «Проекция» появится на экране.

**Если на вкладке Actions ничего нет:** папка `.github` могла не загрузиться
(некоторые системы скрывают папки с точкой). Тогда нажмите **Add file → Create new file**,
в имени напишите `.github/workflows/android.yml`, вставьте содержимое файла
`ci/android.yml` из архива и нажмите **Commit changes**.

**Обновить приложение:** загрузите изменённые файлы так же — новая сборка появится в Releases.
Установите поверх старой, мерки сохранятся.

## 2. Собрать в Android Studio (на своём компьютере)

Нужны: Node.js 20+ (https://nodejs.org) и Android Studio (https://developer.android.com/studio).

```bash
npm install
npm run android:init      # скачает модель и шрифты, создаст папку android
npm run android:open      # откроет проект в Android Studio
```

В Android Studio: **Build → Build App Bundle(s) / APK(s) → Build APK(s)**
или кнопка ▶ с подключённым телефоном. После правок в папке `www`: `npm run android:sync`.

---

## 3. Запустить на ноутбуке

**Windows:** дважды щёлкнуть `start.bat`. **macOS / Linux:** `start.command`.
Нужен Node.js или Python. Откроется браузер с адресом `http://localhost:8000`.

Для работы скана без интернета один раз выполните `npm install` и `npm run vendor` —
модель распознавания сохранится в папке `www/vendor`. Без этого она загрузится
из интернета при первом скане (около 10 МБ).

В Chrome или Edge приложение можно установить: значок ⊕ в адресной строке.

## 4. Опубликовать в Google Play

Приложение для Google Play собирается тем же GitHub Actions, что и APK, но в формате **AAB**
и с подписью. Android 16 (API 36), как требует Google Play с осени 2026.

**Шаг 1. Ключ подписи (один раз).**
1. Придумайте длинный пароль (16+ символов, буквы и цифры) и **запишите его на бумаге**.
2. На GitHub: репозиторий → **Settings → Secrets and variables → Actions → New repository secret**.
   Имя: `KEYSTORE_PASSWORD`, значение: ваш пароль → **Add secret**.
3. **Actions → «Собрать APK» → Run workflow.** При первой сборке ключ создаётся сам и
   сохраняется в репозиторий зашифрованным (`signing/upload.jks.enc`). Без пароля его не открыть.
4. Когда сборка позеленеет: откройте её → внизу **Artifacts → proekciya-google-play-aab** →
   скачайте и распакуйте. Внутри `proekciya.aab`: этот файл загружается в Google Play.

Каждая следующая сборка получает новый номер версии сама.

**Шаг 2. Политика конфиденциальности (один раз).**
Settings → **Pages** → Source: **GitHub Actions**. После следующей загрузки файлов
приложение откроется как сайт, а политика будет по адресу
`https://ВАШ-НИК.github.io/ИМЯ-РЕПОЗИТОРИЯ/privacy.html`.
В файле `www/privacy.html` замените `ВАШ-EMAIL` на свой адрес.

**Шаг 3. Аккаунт разработчика.** https://play.google.com/console → разовый взнос 25 $,
подтверждение личности (паспорт) и телефона Android.

**Шаг 4. Приложение в Play Console.** Create app → название, язык, «Приложение», «Бесплатно».
Тексты, ответы на «Безопасность данных» и графика лежат в папке `store/` (`store/listing.md`).

**Шаг 5. Закрытое тестирование: 12 человек, 14 дней.** Для новых личных аккаунтов это обязательно.
Testing → Closed testing → загрузите `proekciya.aab` → добавьте email-адреса 12+ тестировщиков
(друзья, семья) → отправьте им ссылку «Join on the web». Они должны **принять приглашение,
установить приложение и не выходить из теста 14 дней подряд**.

**Шаг 6. Выпуск.** Через 14 дней: Dashboard → **Apply for production** → ответить на вопросы
о тесте → проверка Google (обычно до 7 дней) → Production → Create release → тот же или новый AAB.

Важно:
- Имя пакета `com.proekciya.app` после первой загрузки поменять нельзя.
- Пароль `KEYSTORE_PASSWORD` не теряйте. Если потеряете, ключ загрузки можно сбросить через
  поддержку Google Play (Play App Signing), но это займёт время.
- На телефоне нет ноутбука: точное удаление фона (bg_remover) и ИИ по ключам на ноутбуке там не работают.
  Фон убирается встроенным способом (MediaPipe). Чтобы на телефоне работали ИИ-стилист и скидки,
  нужен сервер из папки `server/` (Cloudflare Worker) и его адрес в `www/js/config.js` → `chatUrl`.

## Что умеет

**Модель.** Реалистичная фигура строится заново по каждой мерке: плечи, грудь,
талия, бёдра, ягодицы, руки с пальцами, лицо, волосы. Обхваты груди, талии и бёдер
на модели совпадают с введёнными до сантиметра — это видно по жёлтым сантиметровым
лентам с подписями. Виды: тело, в одежде, голограмма. Вращение пальцем, мышью
или стрелками; щипок или колёсико — приближение; двойное касание — сброс вида.

**Мерки.** Все, что нужны для подбора одежды: рост, обхват шеи, ширина плеч, обхват груди,
обхват под грудью (для женщин), талия, бёдра, обхват бедра, длина рукава, длина ноги
по внутреннему шву, обхват головы, длина стопы. Кнопки −/+, ввод цифрами, ползунок, голосом
(«рост 180, грудь 100, шея 39, стопа 26,5»). У каждой мерки своя сантиметровая лента на модели:
когда вы вводите мерку, её лента подсвечивается, а модель поворачивается к ней. Нажатие на подпись
ленты открывает нужное поле.

**Размер.** Буква (S, M, L…), европейский и российский размер верха и низа, джинсы W/L,
рубашка (воротник и рукав), бюстгальтер (например, 75B), обувь (EU и RU), головной убор,
тип фигуры. «Поделиться» отправляет мерки в мессенджер, «Сохранить» — файлом.

**Стилист.** Определяет цветотип (весна, лето, осень, зима) по коже, волосам и глазам
и показывает вашу палитру. По типу фигуры и росту объясняет, что подчеркнуть и чего избегать.
Подбирает готовые образы в шести стилях (повседневный, смарт-кэжуал, деловой, спортивный,
уличный, вечерний) под сезон: каждая вещь с цветом, кроем под вашу фигуру и размером.
Кнопка «Примерить на модели» одевает 3D-фигуру в этот образ, «Прочитать» — озвучивает его.

**Скан по фото.** Камера с таймером 10 секунд: поставьте телефон, отойдите, встаньте.
Программа сама находит человека (Google MediaPipe), вырезает силуэт и меряет
ширину на уровне груди, талии и бёдер, длину ноги, ширину плеч. С фото сбоку
обхваты точнее. Если фигура не нашлась — можно отметить точки вручную с лупой.

**Лицо.** Селфи или фото накладывается на лицо модели. Цвет кожи подбирается
по фото. Цвет кожи, волос и глаз можно выбрать.

**Доступность.** Озвучка (голос Android), субтитры, пошаговый ввод, крупный текст,
высокий контраст, светлая и тёмная тема. Все кнопки подписаны для TalkBack.

## Примерочная по фото (главный экран)

3D-модель выключена (`mode3d: false` в `www/js/config.js`; `true` — вернуть 3D).
Клиент загружает своё фото в полный рост (или снимает камерой), затем добавляет вещи с фото товара:
«Добавить вещь», «Примерить товар по фото» в «Магазинах» или «Примерить» в корзине.
Фон фото товара убирается сам (однотонный фон), вещь ставится по плечам, бёдрам и щиколоткам
(распознавание MediaPipe; без него — по центру). Дальше всё вручную: перетащить пальцем,
растянуть и повернуть двумя пальцами или жёлтой ручкой, ширина, длина, поворот, прозрачность,
ластик и «Вернуть», порядок слоёв. «Сохранить снимок» — картинка примерки.
Фото и вещи хранятся только на устройстве.

## Ваше фото вместо модели (удаление фона)

Вид «Моё фото» или кнопка «Фото спереди» во вкладке «Скан»: программа убирает фон, и на сцене вместо 3D-модели появляетесь вы — с ростом, грудью, талией и бёдрами. На фото можно надевать вещи из магазинов, а фон поправить кистью («Поправить фон» → «Стереть» / «Вернуть»).

Точное удаление фона делает модуль `bg_remover` (нейросеть BiRefNet) — он работает на ноутбуке, фото никуда не уходит.

1. Установите Python 3.10+ с python.org (галочка «Add Python to PATH»).
2. Скопируйте папку `bg_remover` (файлы `core.py`, `fix.py`, `server.py`, `__main__.py`, `__init__.py`) в `proekciya\tools\`.
3. В командной строке: `cd proekciya\tools` и `pip install -r requirements.txt`.
4. Запускайте `start.bat` как обычно — модуль удаления фона включится автоматически вместе с программой и выключится, когда закроете окно. Первый запуск скачает модель (~930 МБ), одно фото обрабатывается до минуты.

Без модуля (и на телефоне) фон убирается быстрым способом (MediaPipe, нужен интернет при первом запуске) — грубее, но сразу. Адрес модуля задаётся в `www/js/config.js` → `bgUrl`.

## ИИ-примерка: вы в выбранной одежде

Кнопка «Примерить» в корзине (и в окне «Примерить товар по фото») показывает **вас в этой вещи** — реалистично, со складками и посадкой.
Работает через сервис FASHN (модель `fal-ai/fashn/tryon/v1.6` на fal.ai), около 7 центов за одну примерку.
Подходит для верха, низа и платьев; обувь и головные уборы примеряются по-старому (накладкой).

Что нужно:
1. Ваше фото в полный рост («Моё фото»).
2. Фото вещи: в магазине сохраните картинку товара или сделайте скриншот → «Примерить товар по фото» → «В корзину».

Настройка на ноутбуке (один раз):
1. Зарегистрируйтесь на fal.ai, пополните баланс (хватит нескольких долларов) и создайте ключ API (Dashboard → Keys).
2. Создайте в папке `proekciya` текстовый файл **`fal.key`** и вставьте в него ключ одной строкой. Никому его не пересылайте.
3. Перезапустите `start.bat`.

Для телефона ключ кладётся в секрет сервера ИИ-стилиста: `npx wrangler secret put FAL_KEY` (см. `server/README.md`).

Перед первой примеркой программа спрашивает согласие: ваше фото и фото вещи уходят в сервис только для этой примерки.
Без ключа или без согласия работает обычная примерка — вещь накладывается на фото прямо в программе.
Каждая следующая вещь надевается поверх предыдущей (можно собрать образ); «С моего фото» — начать заново.

## Приветствие

При первом запуске открывается окно приветствия: что умеет программа, как работает ИИ-стилист,
выбор языка и фигуры (мужчина/женщина). Снова открыть: вкладка «Доступ» → «О программе».

## Поиск в магазинах

Вкладка «Магазины»: клиент пишет, что ищет («синие джинсы», «наряд на свадьбу»), программа добавляет
его размер (буквенный, EU, W/L для джинсов, размер обуви) и даёт ссылки на поиск в магазинах выбранной страны:
Бельгия, Нидерланды — Zalando, Amazon, bol.com, Vinted, ASOS; Германия — + About You; Польша — Allegro;
Россия — Wildberries, Ozon, Lamoda; везде — Google Shopping.
С подключённым ИИ-стилистом запрос разбирает ИИ: делит образ на вещи и пишет запросы на языке магазинов страны.
Без ИИ текст уходит как написан, а вещи из готовых образов стилиста переводятся словарём приложения.
Кнопка «Найти в магазинах» есть у каждого образа стилиста и у образов в чате.

## Местоположение, погода и скидки

- **Магазины → «Определить местоположение»**: программа узнаёт страну и город (с вашего разрешения), сама выбирает страну магазинов,
  показывает магазины одежды этой страны и магазины рядом (OpenStreetMap) с маршрутом. Координаты хранятся только на устройстве.
- **Стиль → «Погода и что надеть»**: прогноз на день (Open-Meteo, без ключа) и совет, что надеть; кнопка «Прочитать вслух»,
  можно включить чтение прогноза каждое утро при первом касании.
- **Магазины → «Скидки и распродажи»**: ИИ-агент ищет в интернете новости магазинов страны и говорит, где и когда купить дешевле
  (Claude с веб-поиском, около 1–5 центов за проверку). Можно включить проверку раз в день.

### Все магазины рядом (Google Карты)
«Рядом с вами» показывает магазины одежды, обуви, универмаги, спорт, детскую одежду и секонд-хенд в выбранном радиусе (1–20 км).
Самые полные данные — из Google Карт: создайте ключ Places API (console.cloud.google.com → APIs & Services → включить «Places API (New)» →
Credentials → API key; нужен платёжный профиль, но первые 5 000 запросов в месяц бесплатны) и положите его в файл **`google.key`** в папке `proekciya`,
затем перезапустите `start.bat`. Одно обновление списка — около 6 запросов; список хранится сутки.
Без ключа используется OpenStreetMap (бесплатно, но магазинов там меньше и серверы бывают перегружены). Для телефона — секрет сервера `GOOGLE_PLACES_KEY`.

### ИИ на ноутбуке без сервера в интернете
Создайте в папке `proekciya` файл **`anthropic.key`** с ключом Anthropic API (console.anthropic.com → API Keys) и перезапустите `start.bat`.
Тогда ИИ-стилист, умный поиск и поиск скидок работают прямо через программу на ноутбуке. Ключ никому не пересылайте.
Для телефона ключ кладётся в секрет сервера (`server/README.md`).

## ИИ-стилист (чат)

На вкладке «Стиль» — чат со стилистом: он знает мерки, размер, фигуру и цветотип клиента,
отвечает на выбранном языке и может предложить образ с кнопкой «Примерить на модели».
Пока в `www/js/config.js` не указан адрес сервера, чат работает в демо-режиме (отвечает встроенный стилист).
Как подключить настоящий ИИ — в `server/README.md`. Перед первым вопросом приложение спрашивает согласие:
сообщения и мерки уходят на сервер, фото — никогда.

## Языки

Меню с глобусом вверху экрана: русский, English, Nederlands, Français, Deutsch, Polski.
Выбор запоминается; при первом запуске берётся язык телефона. Озвучка говорит на выбранном языке
(голосовой ввод мерок пока понимает только русский).
Словари — в папке `www/i18n`: каждая строка файла `en.txt` (и других) — перевод той же строки `ru.txt`.
Новый язык: скопируйте `en.txt`, переведите построчно и добавьте язык в список `LANGS` в `www/js/i18n.js`.

## Реалистичная модель (MakeHuman)

Мужская и женская реалистичные модели уже встроены (`www/models/man.obj`, `woman.obj`) и включены
по умолчанию. Они собраны скриптом `scripts/build-models.py` из открытых файлов MakeHuman (CC0):
тело с плавной поверхностью, глаза, причёска. Ниже — как заменить их своей моделью.

Встроенная фигура строится по меркам сама. Для фотореалистичного человека
(настоящее лицо, глаза, брови, волосы) можно взять модель из бесплатной программы
MakeHuman — приложение подгонит её под все ваши мерки так же точно.
Всё, что экспортировано из MakeHuman, можно свободно использовать (лицензия CC0).

1. Скачайте MakeHuman 1.2: http://www.makehumancommunity.org (Windows, macOS, Linux).
2. Вкладка **Main → Modelling**: выберите пол (ползунок Gender до конца влево — женщина,
   вправо — мужчина). Остальное можно не трогать: фигуру приложение подгонит по меркам.
3. **Geometries → Clothes**: снимите одежду (иначе мерки будут неточными).
   **Hair**, **Eyebrows**, **Eyelashes**, **Eyes** — выберите по вкусу.
4. **Pose/Animate → Pose**: стандартная поза (руки немного в стороны). Не используйте
   T-позу и позы, где руки прижаты к телу.
5. **Files → Export**: формат **Wavefront obj**, единицы **centimeter**, галочка
   **Feet on ground**, имя файла **man** (или **woman**) → **Export**.
   Файлы появятся в «Документы/makehuman/v1py3/exports»: `man.obj`, `man.mtl`
   и папка `textures`.
6. В приложении: вкладка **Лицо → Загрузить модель из MakeHuman**, выберите сразу
   все файлы (`.obj`, `.mtl` и картинки из `textures`). Переключатель «Реалистичная»
   включится сам. Модель запоминается на устройстве.

**Чтобы модель была встроена в APK:** положите `man.obj`, `man.mtl` (и/или `woman.*`)
в папку `www/models`, а картинки — в `www/models/textures`, и загрузите на GitHub
вместе с остальными файлами. Сборка возьмёт их в приложение.

Цвет кожи реалистичной модели берётся из палитры на вкладке «Лицо», волосы и глаза —
из экспорта MakeHuman. Ленты замеров, подсветка, одежда, стилист и лицо по фото
работают и с ней.

## Приватность

Фото, мерки и лицо обрабатываются и хранятся только на устройстве.
В интернет уходит только то, что нужно для функции, которую вы сами включили: координаты
для погоды и магазинов рядом, вопрос и мерки для ИИ-стилиста. Подробно: `www/privacy.html`.

## Точность

Скан по фото: примерно ±3–5 см, с фото сбоку — точнее. Лучше всего в облегающей
одежде, без обуви, на ровном фоне, когда камера на уровне пояса. Размеры считаются
по европейской сетке и служат ориентиром: у брендов посадка отличается.

## Устройство проекта

```
www/                 приложение (HTML, CSS, JS) — одно для телефона и ноутбука
  js/body.js         построение 3D-тела по меркам (работает в фоновом потоке)
  js/template.js     реалистичная модель MakeHuman: загрузка и подгонка под мерки
  js/viewer.js       3D-просмотр на WebGL: свет, тени, ленты, глаза, голограмма
  js/scan.js         автоматический скан: поиск фигуры и замер по силуэту
  js/camera.js       камера с таймером
  js/native.js       голос, распознавание речи, «Поделиться» и файлы на Android
  js/stylist.js      стилист: цветотипы, советы по фигуре, образы
  js/app.js          интерфейс, мерки, размеры, лицо, доступность
www/models/          сюда можно положить модель MakeHuman (встроится в APK)
scripts/             скачивание модели и шрифтов, настройка Android, локальный сервер
.github/workflows/   автосборка APK и AAB для Google Play, сайт на GitHub Pages
store/               тексты, значок, баннер и скриншоты для Google Play
www/privacy.html     политика конфиденциальности
assets/logo.png      значок приложения
capacitor.config.json  настройки Android-обёртки (Capacitor)
```
